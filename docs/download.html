Setup program (.exe)

Windows may show a SmartScreen warning when you run it: here is why.

Run it and choose Install. It installs for your account only, so Windows never asks for administrator rights. Then choose Add, pick a script or a folder and press Run. Run setup again to update, repair or go back a version; to remove it, uninstall from Settings, then Apps.
